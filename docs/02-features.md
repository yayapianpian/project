# 02 功能規格

本文件先定義貫穿整個平台的**三大學習機制**，再逐頁說明 12 個頁面的功能。每個按鈕都列出它實際會做什麼（第 7 階段會逐一用 Playwright 驗證）。

---

## A. 三大學習機制（全站共用）

### A1. 三段式引導：像老師一樣，不直接給答案

適用：所有 SQL、Python、試算表、DAX、資料分析題（選擇題只有「解析」，不需要三段）。

| 作答次數 | 系統回應 | 來源 |
|---|---|---|
| 第 1 次答錯 | **指出錯誤發生在哪裡**：例如「第 3 行 `GROUP BY` 少了 `region`」「你的結果多出 108 列，JOIN 可能造成重複」「`df['price']` 有 37 筆缺失值尚未處理」 | 批改器自動診斷（本機規則，不需 AI） |
| 第 2 次答錯 | **給一個解題方向的提示**，不給程式碼：例如「先想想：要先算每位客戶的首購日，再跟訂單表比對。可以用 CTE 分兩步。」 | 題目內預先撰寫的 `hints[]`；有 AI 時可依使用者的程式碼客製提示 |
| 第 3 次答錯 | **完整答案 + 逐行解析 + 常見錯誤 + 為什麼這樣寫** | 題目內的 `solution`、`explanation`、`commonMistakes` |

規則：
- 任何時候都可以按「我想直接看答案」，但需二次確認（「看答案後此題熟練度只計 0 分，確定嗎？」）。
- 熟練度計分隨提示等級遞減：不用提示 100%、用第一段 80%、第二段 50%、看完整答案 0%（但會進錯題本）。
- 看過答案的題目，系統會在 3 天後出**同概念的變形題**，確認是真的學會，而不是記住答案。

### A2. 企業主管出題模式

每份產業任務都以「你剛進公司，主管交辦任務」的形式呈現。範例：

> **模擬企業任務｜電商產業・數據分析師**
> **營收下降 15%，你會怎麼分析？**
> 主管（營運部 王經理）：「這個月營收比上月掉了 15%，週五的週會我要知道原因，以及接下來可以怎麼做。」
>
> 你需要完成：
> 1. 使用 SQL 查詢銷售資料
> 2. 使用 Python 清理及分析資料
> 3. 找出營收下降的主要原因
> 4. 使用 Power BI 製作分析儀表板
> 5. 提出三項改善建議
>
> 評分依據：技術正確性、分析邏輯、商業洞察、建議可行性

流程設計：
1. **任務簡報**：公司背景、你的職責、主管的原話、截止「工作天」、交付物格式。
2. **追問主管**（釐清需求）：可選擇要問的問題（例如「營收是含稅還是未稅？」「要比上月還是去年同期？」），每個問題有預先寫好的回答。問到關鍵問題會加「分析邏輯」分；完全不問直接做，會在回饋中被指出。這是實際職場最常被忽略的能力。
3. **分步任務**：每步有可驗證的檢查點（SQL 查詢結果、Python 清理後資料筆數、找到的主因＋量化貢獻）。
4. **交付**：結構化報告（背景／問題／資料／清理／方法／結果／洞察／建議）＋ 儀表板截圖。
5. **主管回饋**：依四項評分標準評分；結構化部分自動比對 `groundTruth`；文字部分用評分表（見 04）。
6. **合格門檻**：四項各自 ≥ 60% 且總分 ≥ 70 才能「結案」並放入作品集。只有圖表、沒有洞察與建議 → 不合格。

### A3. 學習弱點追蹤與自動補強

每一題都標記 1–3 個**概念標籤**（例如 `sql.join.left`、`sql.window.rank`、`py.pandas.missing`、`biz.metric.aov`）。

觸發條件（任一成立即觸發）：
- 同一概念**連續 3 次答錯**；
- 同一概念最近 5 次作答正確率 < 40%；
- 測驗後該概念熟練度 < 0.4 且已有 ≥ 4 筆作答證據。

觸發後：
1. 建立「補強任務」，插入到**明天**的每日任務最前面（必要時把原排程往後推，計畫頁會顯示「因補強順延 1 天」）。
2. 補強內容 = 該概念的重點複習（短版教學）＋ 3–5 題由易到難的專屬練習 ＋ 1 題變形應用題。
3. **章節閘門**：該概念所屬章節的「下一章」暫時鎖定，直到補強測驗 ≥ 80%。可手動「暫時略過」，但儀表板會持續顯示紅色弱項，且最多略過 2 次。
4. 補強通過後，該概念進入間隔複習（3 天、7 天、21 天後各出一題）。

例：SQL 測驗連續三次 JOIN 都答錯 → 系統安排「JOIN 補強：LEFT vs INNER、JOIN 造成列數膨脹、多表 JOIN 順序」，不讓你直接進入「子查詢」。

## B. 頁面規格

左側導覽列固定 12 項，手機版收合為抽屜選單；右上角有深／淺色切換、備份、設定。

### 1. 首頁與學習總覽（Dashboard）

| 區塊 | 內容 |
|---|---|
| 今日任務 | 今天的 3–5 個任務（含補強任務），每項可直接「開始」；完成後打勾 |
| 180 天進度 | 第 N 天／180、目前階段、進度條；「實際進度 vs 計畫進度」差距（落後幾天） |
| 本週目標 | 本週要完成的單元、測驗、專案里程碑 |
| 技能雷達圖 | 6 大能力（資料處理、SQL、Python、Power BI、商業分析、專案表達）目前分數 |
| 成績統計 | 最近 10 次測驗分數折線圖、平均分數 |
| 弱項分析 | 熟練度最低的 5 個概念 + 「去補強」按鈕 |
| 已完成專案 | 已結案專案數與最新一個 |
| 下一個學習任務 | 一顆大按鈕，直接進入下一個未完成任務 |

首次進入（沒有任何資料）時，首頁只顯示「開始能力診斷」引導。

### 2. 180 天學習路線（Roadmap）

- 6 個階段的時間軸 → 展開為週 → 每天任務。
- 狀態：已完成／進行中／已測驗免修（test-out）／補強插入／鎖定。
- **能力診斷後個人化**：診斷達到「具備獨立分析能力」的主題可以「測驗免修」，省下的天數自動分配給弱項與作品集專案。
- 「重新排程」按鈕：落後時可選擇（a）延長總天數、（b）壓縮選修內容、（c）週末補課，系統重算後預覽差異再確認。
- 每週固定有 1 個「商業分析思維」小任務，不只在第五個月才練商業分析（呼應「SQL 與商業分析優先級最高」）。

### 3. 課程教學中心（Lessons）

每個單元固定結構（缺一不可，由 `validate-content` 腳本檢查）：
1. 這個技能在工作上用在哪裡（實際案例）
2. 教學內容（由淺入深）
3. 操作步驟
4. 範例程式碼（可一鍵送到練習室執行）
5. 練習題（內嵌，使用三段式引導）
6. 標準答案與詳細解題說明（需作答後或確認後才展開）
7. 常見錯誤
8. 單元小測（3–5 題，結果寫入熟練度）

「標記為已讀」只記錄進度，**不加任何能力分數**。

### 4. SQL 練習室

- 左：資料庫結構（表、欄位、型別、關聯圖）＋題目；右：CodeMirror 編輯器 ＋ 結果表格。
- 按鈕：`執行`（只看結果，不計分）、`提交批改`、`格式化`、`重設`、`查看提示`（依三段式規則逐級開放）、`問 AI 導師`（有 Key 才顯示）。
- 模擬企業資料庫：電商（customers / orders / order_items / products / campaigns）、零售、金融等多套，可切換。
- 自由練習模式：任意查詢、可存成「我的查詢筆記」。
- 題目分級：基礎 → 商業問題（例如「計算每月新客的 30 天回購率」）→ 面試題。

### 5. Python 練習室

- 類似 Jupyter 的多儲存格介面（可新增、執行、全部執行、清除輸出）。
- 預載資料集為 DataFrame；matplotlib 圖表直接顯示。
- `提交批改` 執行隱藏檢查；錯誤訊息會附上中文解讀（例如 `KeyError: 'Price'` →「欄位名稱大小寫不符，實際欄位是 `price`」）。
- 狀態列顯示 Python 環境載入進度；可中止執行。

### 6. Power BI 實戰中心

- 每個實戰：下載資料集（CSV / xlsx）→ 逐步任務（Power Query 清理、建立星型模型、DAX 量值、視覺化、報告頁）。
- **DAX 練習**：題目描述＋資料模型圖；使用者貼上 DAX、回填在 Power BI 算出的數值，平台比對正確值並檢查關鍵函式。
- **儀表板交付**：上傳截圖 + 填寫「這頁要回答什麼商業問題、主管 30 秒內該看到什麼」；依評分表評分（KPI 選擇、版面層級、篩選互動、圖表選擇是否正確、是否有結論）。
- 誠實標示：「平台無法開啟你的 .pbix 檔，評分依據為數值驗證、截圖與評分表。」

### 7. 測驗中心

- 題型：單選、多選、填空、SQL 實作、Python 程式、資料分析、商業情境；另有**限時模擬考**（例如 60 分鐘企業筆試）。
- 測驗模式：單元小測、階段測驗、弱點測驗（只出弱項概念）、錯題重練、限時模擬考。
- 測驗中不給提示（模擬考試情境）；限時模擬考可暫停 0 次，倒數結束自動交卷。
- 結果頁：分數、每題正確答案、詳細解析、**錯誤原因分類**（觀念錯誤／語法錯誤／粗心／時間不足）、能力評級、建議複習單元（可直接點進去）。
- 錯題自動進錯題本（Leitner 間隔複習：1 → 3 → 7 → 21 天）。

### 8. 產業模擬專案

- 6 產業可自由選擇：電商、金融、零售、行銷、製造、物流。
- 每個產業至少 2 個任務（初階／進階），各有獨立資料集、公司背景、職責、主管問題、交付要求、評分標準（詳見 A2）。
- 專案可存草稿、可多次提交（保留版本），每版都有主管回饋。

| 產業 | 主要任務範例 | 核心指標 |
|---|---|---|
| 電商 | 營收下降 15% 原因分析；RFM 分群升級為「分群 → 行動方案 → 預估效益」 | 回購率、客單價（AOV）、轉換率、LTV |
| 金融 | 信用卡交易異常偵測規則設計；客戶交易行為分群 | 逾期率、異常交易比例、規則命中率與誤判率 |
| 零售 | 門市績效排名與低績效原因；滯銷品與庫存週轉 | 坪效、庫存週轉天數、售罄率 |
| 行銷 | 廣告預算重新分配；漏斗分析 | ROI / ROAS、CAC、CVR、CTR |
| 製造 | 良率下降根因；設備異常偵測 | 良率、OEE、MTBF、不良率 |
| 物流 | 配送延遲原因；每單配送成本分析 | 準時率、延遲率、每單成本、車輛利用率 |

### 9. AI 導師

- 未設定 API Key 時：頁面明確顯示「AI 導師尚未啟用」，並說明如何設定與成本；**所有其他功能照常運作**（三段式提示改用題目預寫內容）。
- 啟用後功能：解答學習問題、依使用者程度調整解釋、循序漸進提示、批改 SQL/Python、分析錯誤原因、依評分表評估商業報告、根據弱項推薦補強。
- 預設「引導模式」：先反問、再提示、最後才給解答；使用者明確說「請直接給答案」才給。
- 每則對話顯示實際使用的 tokens 與估算花費；可設定每月預算上限，超過即停用。
- 詳見 [05-ai-tutor.md](05-ai-tutor.md)。

### 10. 個人作品集

- 只收「已結案」（通過主管評分門檻）的專案。
- 每個作品包含：專案背景、商業問題、使用資料、資料清理過程、分析方法、使用工具、分析結果、商業洞察、行動建議、成果展示（圖表／截圖）。
- 顯示主管評分與評語；可排序、隱藏。
- 匯出：單頁 HTML（可放 GitHub Pages）與 Markdown（可貼到 GitHub README / Notion），作為求職作品集。

### 11. 求職面試中心

- **履歷工作坊**：用作品集自動產生「專案經驗」條列草稿（STAR 格式、含量化成果），使用者修改；提供初階數據分析師履歷檢核表。
- **SQL / Python 面試題庫**：依公司常見題型分類，可限時練習。
- **企業數據分析筆試模擬**：90 分鐘，SQL + Python + 商業情境綜合題。
- **主管面試模擬**：情境題（「如果主管說你的數字跟財務部不一樣，你怎麼處理？」）、「說明你的專案」練習（計時 3 分鐘），依評分表自評；有 AI 時可文字對答並依評分表回饋。
- 面試準備度分數（獨立顯示，不混入技能分數）。

### 12. 個人能力分析

- 100 分制總分與 6 大能力分數（見 04），每項顯示分級、證據數量、可信度。
- 每個能力展開為概念熟練度熱力圖（例如 SQL 底下 12 個概念）。
- 成長曲線（每週快照）。
- 「距離求職標準還差什麼」：列出低於門檻的項目與對應建議任務。

## D. 能力診斷（初始測驗）

- 約 40 分鐘、30–36 題，分 6 區：資料處理、試算表、SQL、Python、Power BI、商業分析。
- 自適應：每區先出中等難度，答對升難、答錯降難，最多 6 題／區。
- 結合**自我回報**（例如「做過 RFM」「用過 Power Query」），但自我回報只用來決定起始題難度，**不直接加分**。
- 結果：6 區初始熟練度 → 產生個人化 180 天計畫（哪些單元可測驗免修、哪些要加強），並給出「目前分級」與「預估達到求職標準所需週數」。
- 依使用者背景的預期：Power BI、資料清理、商業分析起點較高；SQL、Python 從基礎系統訓練。實際以診斷結果為準。
