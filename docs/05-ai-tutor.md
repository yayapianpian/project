# 05 AI 導師：設定方式、能力邊界與成本

## 1. 誠實聲明

- 平台**本身沒有 AI**。三段式提示、批改、錯誤診斷、弱點偵測、計畫排程全部是**規則與預寫內容**，不需要 AI，也不需要網路。
- 網站內直接對話的 AI 導師是**選用功能**，需要使用者自己申請 API Key（另外付費）；不想付費可使用「複製給 AI」（見第 2 節）。沒有設定時，網站會清楚顯示「AI 導師未啟用」，不會假裝有 AI 回覆。
- AI 的批改與評分是「參考意見」：程式題的對錯仍以平台實際執行結果為準；報告評分的最終分數採保守規則（見 04 第 7 節）。

## 2. 零成本方案：「複製給 AI」（第 2 階段已上線）

API 與 Claude.ai／ChatGPT 的訂閱是**分開計費**的：訂閱方案的額度不能給網站呼叫 API 使用。為了讓沒有 API Key 的使用者也能有 AI 輔助，平台提供「複製給 AI」：

- 出現在：每日任務、課程中心每個主題、診斷結果的每一題、弱項分析、AI 導師頁。
- 按下後，平台把**引導規則**（先問想法 → 第一次只指出錯在哪 → 第二次給方向 → 第三次才給完整答案）、**使用者背景**、**目前能力評估**、**題目／作答／解析或程式碼與錯誤訊息**整理成一段文字，可先修改再複製。
- 使用者貼到自己的 Claude 或 ChatGPT 對話中，使用現有訂閱，**不呼叫任何 API、不產生額外費用**。
- 限制：需要手動貼上；AI 的回覆不會回到平台，因此**不計入能力分數**，能力分數仍只來自平台內的測驗與作品。

## 3. 選用方案：使用者自備 Key（BYOK），瀏覽器直接呼叫

```
瀏覽器 ──HTTPS──▶ Anthropic Claude API
  ▲ Key 只存在你的瀏覽器 IndexedDB，不經過任何第三方伺服器
```

- 使用官方 TypeScript SDK `@anthropic-ai/sdk`，以瀏覽器模式初始化（SDK 要求明確開啟瀏覽器使用旗標，表示你了解 Key 會存在本機）。
- 為什麼不做平台代付：需要後端、會產生費用、Key 外洩風險高。單人使用、Key 存在自己電腦，是此情境下成本最低且合理的做法。
- 風險與對策：Key 只放在本機；**匯出備份時預設不包含 Key**；設定頁提供「清除 Key」；建議在 Anthropic Console 為這把 Key 設定**每月花費上限**。
- 若日後要給多人使用，改為 Cloudflare Workers（免費額度）做代理，Key 放在伺服器端環境變數，前端不變。

## 4. 設定步驟（第 6 階段完成後可用）

1. 到 Anthropic Console（console.anthropic.com）註冊並儲值（預付制，可小額）。
2. 在 Console 建立 API Key，並在「Limits」設定每月花費上限（例如 US$10）。
3. 回到平台「設定 → AI 導師」貼上 Key，選擇模型，設定平台內預算上限。
4. 按「測試連線」：平台送出一則極短訊息確認 Key 有效並顯示實際花費。

## 5. 模型選擇與成本估算

價格為 Anthropic 官方 API 公告的每百萬 tokens 價格（2026 年 10 月資料，實際以官方定價頁為準）：

| 模型 | Model ID | 輸入 | 輸出 | 適合 |
|---|---|---|---|---|
| Claude Opus 5.5（預設） | `claude-opus-5-5` | US$4 | US$20 | 報告評估、商業洞察回饋、主管面試模擬 |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | US$2 | US$10 | 日常程式批改、提示 |
| Claude Haiku 5.5 | `claude-haiku-5-5` | US$0.10 | US$0.50 | 大量簡單問答、預算極低時 |

**單次互動估算**（系統提示＋題目＋你的程式碼＋診斷 約 4,000 輸入 tokens；回覆含思考約 800–1,500 輸出 tokens）：

| 模型 | 每次約 | 每天 20 次 × 180 天 |
|---|---|---|
| Opus 5.5 | US$0.03–0.05 | 約 US$110–170 |
| Sonnet 5.5 | US$0.016–0.025 | 約 US$55–90 |
| Haiku 5.5 | US$0.001 | 約 US$4–6 |

- **Prompt caching**：系統提示與題目內容固定，放在前面並開啟快取，重複互動時這部分輸入費用大幅降低，上表實際花費通常更低。
- 建議組合：日常提示與程式批改用 Sonnet 5.5，專案報告評估與面試模擬用 Opus 5.5（每月可能幾十次），整體半年預估 **US$30–80**。可在設定頁依用途分別選模型。
- 平台內建**花費計量**：每次回覆記錄實際 `usage`（輸入、快取讀取、輸出 tokens）並換算金額；達到預算上限時停用並提示。
- 實際花費取決於使用頻率與回覆長度，上表為估算，不是保證。

## 6. AI 導師的行為設計

固定的系統提示（可快取）要求 AI：

1. **引導優先**：先問使用者「你認為問題在哪？」，再給方向提示，最後才給完整解答；使用者明確說「直接給答案」才直接給。
2. **配合程度**：讀取該概念的熟練度與最近錯誤類型，調整解釋深度（初學者多用類比與逐步說明；進階者直接談效能與寫法取捨）。
3. **以平台事實為準**：每次請求都附上平台的實際執行結果（SQL 結果、錯誤訊息、檢查失敗項），AI 不可宣稱程式「應該可以跑」而與實際結果矛盾。
4. **依評分表評估報告**：輸入評分表與交付內容，要求以結構化 JSON 輸出每項分數與具體理由（引用報告原文），不可只給總評。
5. **推薦補強**：只能從平台提供的概念清單與單元清單中推薦，不得編造不存在的課程。

AI 可存取的資料只有：當前題目、你的作答、執行結果、相關概念熟練度、評分表。不傳送個人資料。
