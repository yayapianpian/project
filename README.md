## 一句話技術方案

**純前端 SPA（Vite + React + TypeScript），部署在免費靜態主機；SQL 用瀏覽器內的 PostgreSQL（PGlite）實際執行，Python 用 Pyodide 實際執行，學習紀錄存在瀏覽器 IndexedDB 並可匯出備份；AI 導師為選用功能，使用者自備 API Key。**

沒有後端伺服器、沒有月費，關掉網路也能練習（AI 導師除外）。

## 在自己的電腦上執行（Windows）

1. 安裝 [Node.js](https://nodejs.org/) 20 以上版本（LTS）。
2. 在專案資料夾開啟終端機：

```bash
npm install
npm run dev        # 開發模式，瀏覽器開啟顯示的網址（通常是 http://localhost:5173）
npm test           # 單元測試
npm run build      # 產生可部署的靜態網站到 dist/
```

端對端測試（需要 Playwright 與 Chromium）：`npm run build && node tests/e2e/smoke.mjs`
